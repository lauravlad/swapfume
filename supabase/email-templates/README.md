# Swapfume email templates (Supabase Auth)

Paste each file into Supabase → Authentication → Emails → Templates.

| Supabase template | File | Subject |
|---|---|---|
| Confirm signup | confirm-signup.html | Confirm your Swapfume account 💐 |
| Reset password | reset-password.html | Reset your Swapfume password |
| Change email address | change-email.html | Confirm your new Swapfume email |
| Magic link | magic-link.html | Your Swapfume sign-in link |

Sent through Resend (smtp.resend.com, sender hello@swapfume.com). Brand colours from css/styles.css.
